ER Sense - auto-capture test

Open the ER Sense extension popup first (it should say "Watching this page"). Then click a button below to throw a real page error. The extension icon should show a number badge, and the popup will list the error.

Note: throwing an error by typing it into the DevTools Console will not be captured - the browser reports console-typed errors only to DevTools, not as a page error event. Use these buttons instead (or reload the page to fire one automatically after 1 second).
